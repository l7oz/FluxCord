# attic

مساحة أرشيف للمواد المهجورة أو المرجعية — **لا يُبنى منه شيء** ولا يُستورد من `src`.

| المحتوى | ما هو |
| --- | --- |
| `drafts/BetterMicrophoneasd` | مسودة ميكروفون محسّن — لم تكتمل |
| `drafts/FakeDeafen` | مسودة FakeDeafen قديمة (النسخة العاملة في `src/fluxplugin/fakeDeafen`) |
| `drafts/usercalltimer/plan.txt` | خطة فارغة لميزة مؤقّت المكالمات |
| `install.sh` | نسخة قديمة من سكربت التثبيت (الأحدث في `Flxuilotl/install.sh`) |
| `keys-mapping.json` | خريطة مفاتيح مرجعية (≈1MB) لم تعد مستخدمة |
| `navIds.md` | ملاحظات مرجعية عن NavIDs الخاصة بديسكورد |

إذا لزم أي ملف منها لاحقًا انقله إلى مكانه الصحيح داخل `src` بدل نسخه من هنا.
